# n8n Automation Guide

## Overview

n8n connects your content pipeline: RSS ingestion → AI writing → WordPress draft → publish → frontend revalidation.

```
External RSS Feeds
      │
      ▼
┌──────────────┐
│  n8n Trigger │  (RSS / Schedule / Webhook)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Filter Node │  (Dedup, relevance check)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  OpenAI Node │  (Generate article: title, body, AEO fields)
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  WP REST API │  (Create draft post with all fields)
└──────┬───────┘
       │ (on manual review & publish)
       ▼
┌──────────────┐
│  Revalidate  │  (POST /api/revalidate → ISR refresh)
└──────────────┘
```

## Install n8n

### Option A: Self-hosted on VPS (recommended)

```bash
# Install n8n globally
sudo npm install -g n8n

# Create systemd service
sudo nano /etc/systemd/system/n8n.service
```

```ini
[Unit]
Description=n8n workflow automation
After=network.target

[Service]
Type=simple
User=foundoors
WorkingDirectory=/home/foundoors
ExecStart=/usr/bin/n8n start
Restart=on-failure
Environment=N8N_HOST=0.0.0.0
Environment=N8N_PORT=5678
Environment=N8N_PROTOCOL=https
Environment=WEBHOOK_URL=https://n8n.foundoors.com/
Environment=N8N_ENCRYPTION_KEY=your-32-char-random-key

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable n8n
sudo systemctl start n8n
```

Add Nginx reverse proxy for `n8n.foundoors.com` (port 5678) — similar to the Next.js config.

### Option B: n8n Cloud

Use [app.n8n.cloud](https://app.n8n.cloud) — easier setup, no self-hosting.

## Workflow 1: RSS → AI Article → WordPress Draft

### Nodes

**1. RSS Feed Trigger**
- Node: `RSS Feed Read`
- URL: competitor RSS feeds, industry sources
- Poll every: 1 hour
- Fields: title, link, content, pubDate

**2. Filter (dedup)**
- Node: `IF`
- Condition: `{{ $json.link }}` not in processed list
- Use `n8n` Set node to track processed URLs in a simple JSON file or Airtable

**3. OpenAI — Generate Article**
- Node: `OpenAI`
- Model: `gpt-4o`
- System prompt:
```
You are a senior tech journalist at Foundoors. Write authoritative, factual news articles.
Output valid JSON with these exact keys:
{
  "title": "SEO-optimized headline (under 65 chars)",
  "content": "Full article HTML (800-1200 words, use <h2> subheadings)",
  "excerpt": "2-sentence summary (under 160 chars)",
  "categories": ["ai-news"],
  "tags": ["company-openai", "funding"],
  "aeo_summary": "1-2 sentence plain-English summary for AI discovery",
  "aeo_key_facts": "fact1\nfact2\nfact3",
  "aeo_why_it_matters": "2-3 sentences on significance",
  "aeo_sources": "https://source1.com\nhttps://source2.com",
  "faq": [
    {"question": "...", "answer": "..."},
    {"question": "...", "answer": "..."}
  ]
}
```
- User prompt: `Write a news article based on this source: {{ $json.title }} — {{ $json.content }}`

**4. Parse OpenAI JSON**
- Node: `Code`
```javascript
const parsed = JSON.parse($input.first().json.message.content);
return [{ json: parsed }];
```

**5. WordPress — Create Draft Post**
- Node: `HTTP Request`
- Method: POST
- URL: `https://api.foundoors.com/wp-json/wp/v2/posts`
- Auth: Basic (WordPress Application Password)
- Headers: `Content-Type: application/json`
- Body:
```json
{
  "title": "{{ $json.title }}",
  "content": "{{ $json.content }}",
  "excerpt": "{{ $json.excerpt }}",
  "status": "draft",
  "categories": [{{ $json.categories }}],
  "tags": [{{ $json.tags }}],
  "meta": {
    "aeo_summary": "{{ $json.aeo_summary }}",
    "aeo_key_facts": "{{ $json.aeo_key_facts }}",
    "aeo_why_it_matters": "{{ $json.aeo_why_it_matters }}",
    "aeo_sources": "{{ $json.aeo_sources }}"
  }
}
```

**6. Send Slack / Email Notification (optional)**
- Notify the editor that a new draft is ready for review

## Workflow 2: On Publish → Revalidate Frontend

This fires automatically when WordPress publishes a post (via webhook).

**1. Webhook Trigger**
- Node: `Webhook`
- URL: auto-generated by n8n (configure this URL in WordPress)
- Method: POST

**2. HTTP Request — Revalidate**
- Node: `HTTP Request`
- Method: POST
- URL: `https://foundoors.com/api/revalidate`
- Headers:
  - `Authorization: Bearer {{ $env.REVALIDATE_SECRET }}`
  - `Content-Type: application/json`
- Body: `{ "slug": "{{ $json.post_name }}" }`

## WordPress Application Password Setup

Required for the n8n WordPress node:

1. Go to WordPress Admin → **Users → Your Profile**
2. Scroll to **Application Passwords**
3. Name it "n8n" and click **Add New Application Password**
4. Copy the generated password (shown once)
5. Use as `username:password` with HTTP Basic Auth in n8n

## ACF REST API Fields

By default, ACF fields are not exposed in the WP REST API. To expose them for n8n:

Add to `functions.php`:
```php
// Expose ACF AEO fields in REST API
add_action('rest_api_init', function() {
    $fields = ['aeo_summary', 'aeo_key_facts', 'aeo_why_it_matters', 'aeo_sources'];
    foreach ($fields as $field) {
        register_rest_field('post', $field, [
            'get_callback'    => fn($post) => get_field($field, $post['id']),
            'update_callback' => fn($val, $post) => update_field($field, $val, $post->ID),
            'schema'          => ['type' => 'string'],
        ]);
    }
    
    // FAQ repeater
    register_rest_field('post', 'faq_items', [
        'get_callback'    => fn($post) => get_field('faq_items', $post['id']) ?: [],
        'update_callback' => fn($val, $post) => update_field('faq_items', $val, $post->ID),
        'schema'          => ['type' => 'array'],
    ]);
});
```

## Content Quality Checklist (for AI drafts)

Before publishing AI-generated drafts, editors should verify:

- [ ] Facts are accurate and sourced
- [ ] Title is under 65 characters and includes primary keyword
- [ ] Featured image added
- [ ] Categories and tags are correct (including entity tags like `company-openai`)
- [ ] AEO Summary is clear and citable (1-2 sentences)
- [ ] FAQ has at least 3 relevant questions
- [ ] Sources URLs are valid and accessible
- [ ] Article passes a plagiarism check
